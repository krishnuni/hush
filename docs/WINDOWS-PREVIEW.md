Hush is an original EPUB/PDF reading room with optional on-device Pocket TTS.

This Windows x64 preview bundles the pinned English/Alba voice pack, the local
inference worker and attribution. Inference runs locally with no paid API or
account token. The optional pack adds roughly 226 MB before compression.

The release workflow must pass frontend tests, storage tests, actual Windows
neural inference and worker-reconnection tests before publishing the installer.
This does not certify physical audio output, every publisher/PDF layout or a
clean-machine installation. The installer is unsigned. Treat this as a
prerelease for evaluation rather than a certified commercial application.

Use SHA256SUMS.txt to verify the installer. Installation and reading preserve
user originals; Hush keeps managed copies and saved positions on this computer.
Model and voice attribution accompanies the installed resources.

The hosted web reader supports local EPUB/PDF reading and offline reopening.
It does not run the desktop neural process. Native mobile inference and
background audio are not included in this preview.
